## 策略清单

### STRAT-001: 金融内容数据准确性优先
- **来源模式**: PAT-001 (AI金融数据幻觉防御)
- **策略内容**:
  ```
  生成任何含市场数据的金融内容时：
  1. 必须先调用yfinance获取实时数据
  2. AI只允许解释数据，不允许"创造"数据
  3. 输出末尾必须标注"数据来源: yfinance"
  4. 禁止AI生成具体价格预测，只允许"支撑/阻力区间"
  ```
- **注入范围**: 全部内容生成任务
- **置信度**: 高
- **最后更新**: 2026-05-05

### STRAT-002: 教育式销售话术结构
- **来源模式**: PAT-003 (教育式销售转化率远高于硬推)
- **策略内容**:
  ```
  所有销售对话/内容的话术结构：
  第1步(价值): 提供1个具体可操作的市场洞察
  第2步(教育): 解释背后的原理(1-2句话)
  第3步(引导): 自然提及"我们的XX工具/研报可以深入分析"
  第4步(CTA): 极低摩擦行动指令("回复1获取")
  禁止: 第1句话就推产品
  ```
- **注入范围**: sales Agent + 社媒内容生成
- **置信度**: 高
- **最后更新**: 2026-05-05

### STRAT-003: Headless浏览器操作规范
- **来源模式**: PAT-002 (Headless浏览器UI定位失败)
- **策略内容**:
  ```
  使用Playwright操作复杂Web编辑器时：
  1. 优先找隐藏input[type="file"]，不依赖可见按钮
  2. 标题输入框优先用侧边栏，不依赖主编辑区
  3. 新平台接入前先手动headless测试一遍完整流程
  4. JS代码绝不用f-string包裹，用page.evaluate(func, arg)
  ```
- **注入范围**: marketing Agent (Substack/TikTok等)
- **置信度**: 高
- **最后更新**: 2026-05-05

### STRAT-004: Token/API Key 管理规范
- **来源模式**: PAT-004 (第三方平台Token/OAuth陷阱)
- **策略内容**:
  ```
  所有第三方平台接入：
  1. 凭证命名必须区分类型：SMTP_ / API_ / OAUTH_ / SESSION_
  2. 新平台接入先读官方API文档Quick Start，不读帮助页面
  3. Token过期是常见故障，每日自动化检查必须包含Token有效性验证
  4. OAuth流程必须走authorization code，不信任"口令生成器"
  ```
- **注入范围**: ai_learning_agent + 所有API调用脚本
- **置信度**: 高
- **最后更新**: 2026-05-05

### STRAT-005: 跨域知识关联检查
- **来源**: FUSION_INDEX.md 设计
- **策略内容**:
  ```
  每次新知识写入knowledge/{domain}/后：
  1. 检查FUSION_INDEX.md中的跨域关联矩阵
  2. 如果新知识与≥2个域有关联，标注关联域
  3. 如果关联涉及销售触发(TA信号→外联)，立即通知销售Agent
  4. 每周五自动运行一次全库跨域关联扫描
  ```
- **注入范围**: ai_learning_agent 主循环
- **置信度**: 中（新策略，待验证）
- **最后更新**: 2026-05-05
