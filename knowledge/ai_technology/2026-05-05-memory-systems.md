# AI Agent 记忆系统 — 2026 核心技术

*学习日期: 2026-05-05 | 来源: State of AI Agent Memory 2026 (Mem0) + arXiv 2512.13564*

---

## 一、三种核心记忆类型

| 类型 | 存储 | 用途 | 实际应用 |
|------|------|------|---------|
| **情节记忆** | "发生了什么" | 具体事件记录 | 客户对话历史、交易记录 |
| **语义记忆** | "已知的事实" | 知识和偏好 | 用户偏好、产品知识 |
| **程序性记忆** | "如何做事" | 操作流程 | PR结构、部署流程、测试模式 |

## 二、四层作用域模型

| 作用域 | 持久性 | 用途 |
|--------|--------|------|
| `user_id` | 跨所有会话 | 用户级偏好和历史 |
| `agent_id` | Agent实例专属 | 特定Agent的经验 |
| `run_id/session_id` | 单次对话 | 临时工作上下文 |
| `app_id/org_id` | 组织共享 | 团队知识库 |

**检索优先级**: 用户记忆 > 会话上下文 > 原始历史

## 三、向量记忆 vs 图记忆

| 维度 | 向量记忆 | 图记忆 (Mem0g) |
|------|---------|---------------|
| 检索方式 | 语义相似度 | 关系路径推理 |
| 知识表示 | "用户提到Python" | "用户在数据管道工作中用Python+Pandas，公司用dbt，正从Spark迁移" |
| 准确性 | 61.0% (LLM Score) | **68.4%** |
| 延迟 | **1.44s** | 2.59s |

**结论**: 图记忆更准确但更慢，向量记忆更快但更浅

## 四、十大方法基准对比

| 方法 | LLM Score | 延迟(p95) | Token消耗 |
|------|-----------|-----------|-----------|
| **Full-context** | 72.9% | 17.12s | ~26,000 |
| **Mem0g（图增强）** | 68.4% | 2.59s | ~1,800 |
| **Mem0** | 66.9% | 1.44s | ~1,800 |
| RAG | 61.0% | 0.70s | - |
| OpenAI Memory | 52.9% | - | - |

**核心权衡**: 准确性(Full-context 72.9%) vs 延迟/成本(Mem0 66.9%，延迟降91%)

## 五、动态遗忘机制

- **低相关性条目衰减**: 对低相关性记忆应用衰减
- **高检索记忆的陈旧性问题**: 高相关性记忆失效前会"自信地错误"
- **开放问题**: 检测高相关性记忆何时陈旧仍是研究前沿

## 六、RAG 技术演进（2026）

### 四大新范式

| 范式 | 核心变化 | 能力跃迁 |
|------|---------|---------|
| **Graph-RAG** | 实体-关系图+路径推理 | 更强事实一致性、多跳推理 |
| **Agentic RAG** | 思考→检索→再思考→再检索 | RAG从模块变成循环 |
| **长期记忆系统** | AI拥有持续记忆 | RAG从"补丁"变成"认知结构" |
| **无检索推理** | 模型内化知识 | 不是RAG失败，而是被更高层吸收 |

### 传统RAG失效原因
1. **检索延迟**: 向量搜索+rerank导致延迟
2. **向量库≠真知识**: 只解决"像不像"不解决"对不对"
3. **AI从问答→执行**: 2023做FAQ，2026做自动分析+持续决策

**核心洞察**: 未来不会再区分"RAG系统"和"AI系统"——记忆、推理、行动、学习将全部融合
