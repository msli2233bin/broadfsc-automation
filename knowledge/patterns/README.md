## 已识别模式

### PAT-001: AI金融数据幻觉防御
- **触发条件**: AI生成内容中包含具体价格/涨跌幅/财务数据
- **根因类型**: 模型能力不足（小模型数字不敏感）
- **失败形态**: Groq llama-3.1-8b 编造行情数据，连用户都能看出来
- **预防策略**:
  1. 所有含数字的内容必须调用yfinance验证
  2. AI生成后追加"数据来源:yfinance"标签
  3. 禁止AI生成具体价格预测，只允许"支撑/阻力区间"
- **出现频率**: 3次+ | **置信度**: 高
- **来源事件**: EVT-001
- **关联域**: finance, ai_tech, marketing

### PAT-002: Headless浏览器UI定位失败
- **触发条件**: Playwright在headless模式下操作复杂SPA编辑器
- **根因类型**: 系统限制（headless下元素不可见）
- **失败形态**: 定位输入框失败，元素在headless中不可见
- **预防策略**:
  1. 优先用 `input[type="file"]` 隐藏输入框上传（不依赖可见按钮）
  2. 标题类输入用侧边栏input，不依赖主编辑器区域
  3. 新平台先手动测试headless兼容性再写自动化
- **出现频率**: 3次 | **置信度**: 高
- **来源事件**: EVT-002, Substack封面图上传
- **关联域**: ai_tech, marketing

### PAT-003: 教育式销售转化率远高于硬推
- **触发条件**: 内容策略制定/销售话术设计
- **根因类型**: 行为金融学（信任前置）
- **成功形态**: 先提供免费价值（分析/教育），再自然引导注册，转化率3-5x
- **预防策略**:
  1. 所有社媒内容末尾加"免费研报/分析"CTA，不直接推产品
  2. 销售对话前3轮禁止提产品，先建立专业形象
  3. 教育内容占比≥70%，营销内容≤30%
- **出现频率**: 5次+ | **置信度**: 高
- **来源事件**: EVT-005, INDEX.md多处验证
- **关联域**: sales, marketing, finance

### PAT-004: 第三方平台Token/OAuth陷阱
- **触发条件**: 接入新平台API（需要用户授权或长期Token）
- **根因类型**: 误导性反馈（官方文档与实际行为不一致）
- **失败形态**: Meta"用户口令生成器"Token无法换长期Token；各类API Key混淆（Brevo SMTP Key vs API Key）
- **预防策略**:
  1. 新平台接入先读官方API文档的"Quick Start"而非帮助页面
  2. Token类型必须验证：短期/长期/session-based区别
  3. 关键凭证写入.env时标注类型（SMTP_/API_/OAUTH_）
- **出现频率**: 3次 | **置信度**: 高
- **来源事件**: EVT-003, EVT-006, Brevo API Key混淆
- **关联域**: ai_tech, marketing

### PAT-005: 中文市场是竞品空白区
- **触发条件**: 竞品分析和市场定位决策
- **根因类型**: 信息分析（竞品策略盲区）
- **成功形态**: 双语内容+中文客服，竞品未覆盖
- **预防策略**:
  1. 内容优先中文发（TikTok中文内容竞品少）
  2. Telegram用中文简体+繁体覆盖大中华区
  3. 竞品英文强势，我们中英双轨错位竞争
- **出现频率**: 2次（需再验证1次升为模式）| **置信度**: 中
- **来源事件**: competitor/README.md, EVT-006
- **关联域**: competitor, marketing, sales
